Colour and type

Rust #BF5824 (light) / #E8743C (dark) is the primary colour: the kite's body, tail and chevron. Wingtip #9E2F45 / #CC4D66 is a wing-gradient colour only — never used for text. The wordmark is Plus Jakarta Sans 700 at −2% tracking, outlined in every SVG above: please don't retype it.

A few rules

  • Match the background. Use the "dark" files on dark backgrounds and the "light" files on light ones — putting the light-mode rust on a dark background turns the wingtip muddy.
  • Leave clear space. One kite head-width on every side (the same as the chevron's apex diameter).
  • Don't go smaller than 64px for the kite, 120px wide for the stacked logo, 20px tall for the horizontal logo, or 12px for the chevron.
  • Don't recolour, add gradients or outline it yourself — the gradient and colours are already part of the file.
  • Don't rotate the chevron. It always points up: it means climb.
